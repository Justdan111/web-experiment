## What it is

Verso is the homepage of an invented design studio in Kyoto. It was built to
learn one thing: how an editorial layout holds together when everything on it
is moving.

## How it works

The page runs as six full-width bands — a hero, a project wall, two work grids,
a news row and a footer. Everything is set in one typeface, and the letter
spacing tightens as the type gets bigger, which is what keeps the whole page
feeling like a single system.

The headline animates one character at a time. Each letter is its own element
that fades and lifts into place, with whole words held together so they never
break across a line. It waits for the font to load before it measures anything,
otherwise the text reflows mid-animation.

The band below it is a wall of project cards travelling diagonally across the
screen as you scroll. Cards that leave one edge are recycled to the other, so
the wall never runs out.

## The hard part

The recycling. Seven cards are visible, but the wall holds ten — the spare
three are what stop a gap opening at the seam as it travels. Getting to that
number took building it wrong first.

Every animation switches off for anyone whose system asks for reduced motion.
